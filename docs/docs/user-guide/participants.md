# What Participants See

Patients and external guests do not use the practitioner portal. They get a
separate, deliberately simple application. Knowing what it looks like helps you
guide someone over the phone.

## Receiving the invitation

Depending on the contact method you chose:

| Channel | What they receive |
|---------|-------------------|
| **Email** | A message with the appointment details and an access link |
| **SMS** / **WhatsApp** | The same, as a text message |
| **Link only** | Nothing. You copy the link from the follow-up and pass it on yourself |

The link is personal: it identifies that one participant. It must not be
forwarded or shared.

## Signing in

Tapping the link opens the patient application and signs them in.

- **Guests reachable only through a link you shared manually** are signed in
  straight away, as long as the link is still valid. Its lifetime is set by your
  administrator (one hour by default) — generate a fresh one from the follow-up
  if it has expired.
- **Anyone with an email address or a phone number** receives a 6-digit
  verification code on that channel and types it in. If the code does not
  arrive, **Resend Code** sends another one.

An expired link shows *This access link has expired. Please ask your
practitioner for a new one.* Open the follow-up, copy the link again, and send
it over.

## Their home screen

Once in, the participant sees:

- their **next appointment**, with the button to join when the time comes
- their **follow-ups**, with the chat, if you gave them *Can see the
  consultation messages*
- their other appointments and any pending request

They join the call the same way you do: a lobby to check camera and microphone,
then the room. The same controls are available — microphone, camera, screen
sharing, chat — minus the moderation ones.

## Requesting a consultation

On instances where it is enabled, a patient can request a consultation on their
own: they pick a specialty, a reason, optionally a time slot among your
[bookable slots](appointments.md#bookable-slots) and optionally a
practitioner. The request lands with the matching practitioner group and appears
in your list once assigned.

## Helping someone who is stuck

| Symptom | What to check |
|---------|---------------|
| "I never got the link" | The contact method and the address or number on the participant. Correct it and resend the invitation |
| "The link says it expired" | Copy a fresh link from the follow-up |
| "It says it is too early" | Joining opens shortly before the start time — 10 minutes by default |
| "Nobody can hear me" | Have them check the microphone selected in the lobby, and the browser permissions |
| "I can't see the chat" | The participant needs *Can see the consultation messages*. Edit the appointment to enable it |
